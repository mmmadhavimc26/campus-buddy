## Interactive adaptation

The building outlines, spatial arrangement, sports grounds, numbered markers and surrounding road labels in `src/campus-map.js` and `src/data.js` are a manual schematic adaptation of the signboard photograph. The redraw changes proportions, simplifies outlines and adds interactive selection, labels and inferred connecting paths. This adapted map geometry and layout data are distributed under **CC BY-SA 3.0**, the same license as the source. This notice does not assign that license to unrelated application code.

The photograph is a historical reference, not an assertion that the campus has remained unchanged. Pedestrian connections are inferred from open spaces in the signboard and need verification. The drawing is not georeferenced; graph weights are not measured metres.

Additional reference discovered: https://github.com/enggayushTiwari/VJTI_WEB_MAP. No code or data copied from that repository.
